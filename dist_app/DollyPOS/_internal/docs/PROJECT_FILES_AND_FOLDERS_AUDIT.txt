[GROUP 1] 🔴 ESSENTIAL CORE PRODUCTION (MUST KEEP - DO NOT DELETE)
================================================================================
These files and directories form the complete core of Dolly POS (source code,
FastAPI API server, React frontend, desktop launcher, and official manuals).

1. backend/app/
   - Purpose: The entire backend core source code.
   - Contains:
     * backend/app/main.py             : FastAPI entrypoint, middleware, health check.
     * backend/app/config.py           : Core system settings, database URLs, JWT keys.
     * backend/app/core/database.py    : Database engine with multi-host connection & SQLite fallback.
     * backend/app/core/security.py    : Password hashing (Bcrypt) & JWT token generation.
     * backend/app/models/             : SQLAlchemy database tables (Product, Bill, User, Khata, etc.).
     * backend/app/schemas/            : Pydantic request/response validation schemas.
     * backend/app/api/                : All 18 API routers (billing, barcode, inventory, etc.).
     * backend/app/services/           : Thermal receipt rendering, barcode generation, AI advisor.
   - Status : CRITICAL CORE (DO NOT DELETE)

2. backend/desktop_app.py
   - Purpose: Native desktop runner. Boots the FastAPI backend server, mounts
     the React production build, and automatically launches Chrome/Edge in
     maximized App Mode.
   - Status : CRITICAL CORE (DO NOT DELETE)

3. backend/build_standalone_exe.py
   - Purpose: PyInstaller compilation script that bundles Python, FastAPI, and
     the frontend into dist_app/DollyPOS/DollyPOS.exe.
   - Status : CRITICAL CORE (DO NOT DELETE)

4. backend/package_single_setup_exe.py
   - Purpose: Packaging engine that compiles the single-click setup wizard
     (DollyPOS_Setup_v1.0.0.exe).
   - Status : CRITICAL CORE (DO NOT DELETE)

5. backend/requirements.txt
   - Purpose: Complete list of Python libraries and versions needed to run the app.
   - Status : CRITICAL CORE (DO NOT DELETE)

6. backend/venv/
   - Purpose: Python Virtual Environment containing all installed Python packages.
   - Status : CRITICAL RUNTIME (DO NOT DELETE)

7. frontend/src/
   - Purpose: Complete modern React 18 + TypeScript POS frontend user interface.
   - Contains:
     * frontend/src/pages/             : Billing, Inventory, Reports, Khata, Settings, etc.
     * frontend/src/components/        : Layout, Statusbar, Thermal Print modals, Cart.
     * frontend/src/store/             : Zustand state stores (cart, auth, settings).
     * frontend/src/utils/api.ts       : Axios HTTP client with JWT interceptors.
   - Status : CRITICAL CORE (DO NOT DELETE)

8. frontend/package.json, vite.config.ts, tailwind.config.js, tsconfig.json
   - Purpose: Frontend dependency definitions, Vite compiler, and Tailwind CSS styles.
   - Status : CRITICAL CORE (DO NOT DELETE)

9. frontend/node_modules/
   - Purpose: Installed JavaScript/TypeScript libraries for React and Vite.
   - Status : CRITICAL RUNTIME (DO NOT DELETE)

10. docs/
